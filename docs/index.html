2. Mục tiêu thực hành

Khởi tạo môi trường lập trình trên GitHub Codespaces, xây dựng API Hello Cloud bằng Node.js và Express, truy cập API qua Internet và đối chiếu trải nghiệm với 5 đặc tính điện toán đám mây theo NIST.

3. Kết quả triển khai API

API được xây dựng bằng Node.js 22.23.4 và Express, hoạt động trên cổng 3000 của GitHub Codespaces.

Khi gửi yêu cầu HTTP GET đến đường dẫn gốc (/), máy chủ trả về dữ liệu JSON gồm:

  • message: Lời chào từ đám mây
  • host: Tên máy chủ
  • platform: Thông tin hệ điều hành
  • cpus: Số bộ xử lý logic
  • memoryGB: Tổng bộ nhớ theo API
  • uptimeSec: Thời gian hoạt động của hệ điều hành
  • time: Thời điểm phản hồi

Kết quả: API chạy thành công, truy cập được từ trình duyệt máy tính và điện thoại qua mạng 4G khi cổng được đặt Public. Sau kiểm tra, cổng 3000 đã chuyển lại Private.

5. Năm đặc tính điện toán đám mây NIST

1. On-demand Self-service

Người dùng tự nhấn Create codespace on main để yêu cầu cấp phát môi trường lập trình, không cần quản trị viên thao tác thủ công.

2. Broad Network Access

API được truy cập từ máy tính và điện thoại qua mạng 4G bằng URL HTTPS. Điều này thể hiện khả năng truy cập qua mạng bằng nhiều loại thiết bị.

3. Resource Pooling

Codespaces sử dụng hạ tầng điện toán do GitHub cung cấp. Người dùng được cấp môi trường có CPU, RAM và hostname riêng mà không phải lựa chọn máy chủ vật lý. Việc gộp tài nguyên được suy luận từ mô hình dịch vụ, chưa được chứng minh trực tiếp chỉ bằng hostname.

4. Rapid Elasticity

Môi trường Codespaces có thể được khởi tạo, dừng và khởi động lại theo nhu cầu. Bài thực hành cho thấy khả năng cấp phát môi trường, nhưng chưa kiểm chứng khả năng tự động tăng giảm CPU hoặc RAM.

5. Measured Service

GitHub Billing Usage ghi nhận mức sử dụng lưu trữ Codespaces là 0.07 GB-month, chi phí phải trả hiện tại là $0. Đây là minh chứng cho việc theo dõi và đo lường mức sử dụng tài nguyên.

6. Nhận xét và kết luận

GitHub Codespaces giúp tạo môi trường lập trình từ xa mà không cần tự cài đặt toàn bộ công cụ trên máy cá nhân. Việc sử dụng URL HTTPS giúp kiểm tra API trên nhiều thiết bị.

Tuy nhiên, thời gian khởi tạo thực tế trong lần thử này dài hơn mục tiêu 2 phút. Nền tảng còn phụ thuộc kết nối Internet, giới hạn tài nguyên và chính sách sử dụng của nhà cung cấp.

Việc tách app.js và server.js giúp tái sử dụng phần ứng dụng trong những bài thực hành tiếp theo.
